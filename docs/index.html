Spotify songs to YouTube Music

A free script that copies the saved songs in your Spotify data export to a private YouTube Music playlist. It runs on your computer. There is no server, no sign-up and no fee.

Check your file first

Drop the YourLibrary.json file from your Spotify export here. The page counts the songs that the script will copy. It leaves out podcasts, episodes and duplicate songs.

The file stays in this browser tab. This page sends nothing to a server. You can turn off your internet and it still works.

Six steps, about 30 minutes

You need a computer with Python 3.9 or newer. Plan for 1 to 2 seconds per song for the search. Spotify can take up to 5 days to send your data, so start step 1 first.

  1. Get your Spotify data

    Use a web browser for this, not the Spotify app.

    1. Go to spotify.com/account/privacy and log in.
    2. Scroll down to Download your data.
    3. Select Account data only. You do not need “Extended streaming history” or “Technical log information”. They take longer to arrive.
    4. Click Request data.
    5. Open the email from Spotify and click Confirm. If you do not confirm, Spotify does not start.
    6. Wait for a second email with the download link. Spotify says this can take up to 5 days. The link stops working after some days, so download it soon.
    7. Unzip the download, usually my_spotify_data.zip. Find the file YourLibrary.json in the folder.

    Your export also holds your email address, listening history and other personal data. Keep it on your computer and do not share it.

  2. Install the script

    Make a new folder and put YourLibrary.json in it. Open a terminal in that folder. On a Mac, type cd and a space in Terminal, drag the folder into the window and press Enter.

    Mac or Linux. Run one at a time:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install ytmusicapi
    curl -O https://raw.githubusercontent.com/kj-gopika/spotify-to-ytmusic/main/s2ytm.py

    Windows PowerShell. Run one at a time:

    py -m venv .venv
    .venv\Scripts\Activate.ps1

    If Windows blocks the last command, run this, then run the last command again:

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    pip install ytmusicapi
    curl.exe -O https://raw.githubusercontent.com/kj-gopika/spotify-to-ytmusic/main/s2ytm.py

    Open s2ytm.py and read it before you run it. It is about 170 lines.

  3. Find your songs on YouTube Music

    This step needs no login. It searches each song and keeps a result only when the title and the artist match.

    python s2ytm.py match YourLibrary.json

    Open matches.csv. An empty videoId means the script found no match. Delete the rows of songs you do not want. If the search stops, run it again. It continues from where it stopped.

  4. Copy your login headers

    Open music.youtube.com in Chrome, Edge or Firefox and log in. Open the developer tools (F12 or Cmd+Option+I) and select Network. Type browse in the filter. Click Library on the page.

    A Copy button replaces your clipboard. So do these in this order:

    1. Click Copy on the command for your computer below. Paste it in the terminal. Do not press Enter yet.
    2. In the developer tools, right-click a browse request with the POST method. Select Copy → Copy request headers.
    3. Go back to the terminal and press Enter. The command saves the headers to headers.txt.

    Mac:

    pbpaste > headers.txt

    Windows PowerShell:

    Get-Clipboard | Set-Content -Encoding utf8 headers.txt

    Do not paste the headers anywhere else. Read the risks below.

  5. Make the playlist

    The script reads headers.txt, deletes it, makes a private playlist and adds the songs 50 at a time.

    python s2ytm.py create --name "My Spotify songs"

  6. Log out

    Log out of music.youtube.com in the browser where you copied the headers. This stops the copied cookies from working. Then log in again if you want to.

Read this before you start

This tool is free and has no warranty. It uses a method that Google does not support. Use it only if you accept these risks.

  • Your headers are your Google login

    The request headers hold your login cookies. A person who has them can use your Google and YouTube account as you, until you log out. Never paste them into a website, a chat, a GitHub issue or an AI assistant. The script reads them from headers.txt on your computer, deletes the file, and keeps the login in memory only.

  • Not an official API

    The script uses ytmusicapi, an open-source library that talks to YouTube Music like a web browser does. Google does not support this. It can stop working at any time. It can be against the YouTube Terms of Service. Google can slow down, flag or limit your account. We do not know how often this happens.

  • Some matches will be wrong

    The script matches by title and artist only. Some results will be a cover, a live version, a remix or a different song with the same name. In one test, 16 of 905 songs (1.8%) had no match. The rate of wrong matches is not known. Check matches.csv before you make the playlist.

  • Only download the script from this repository

    A changed copy of this script can send your cookies to another person. Get it only from the link on this page, and read it before you run it. We do not publish it anywhere else.

  • Song names go to YouTube

    To search, the script sends the title and the artist of each song to YouTube. Your Spotify export also holds personal data, such as your email address and listening history. Do not upload it or share it.

  • Private does not mean secret

    The playlist is private, so other people cannot see it. Google can still see it and can use it for your recommendations. You can change the privacy setting in YouTube Music.

  • It copies songs only

    It copies the saved songs in YourLibrary.json. It does not copy your playlists, albums, artists, podcasts or play counts. It does not delete anything on Spotify.

Questions

Why is this not a website where I log in?

A website like that has to receive the login of every person who uses it. That is a large risk for you and a large responsibility for the person who runs it. A script on your own computer keeps your login with you.

Why not use the official YouTube API?

The official YouTube Data API has a daily limit. A search uses 100 units and adding one video uses 50, from 10,000 units a day. That is about 66 songs a day, so 900 songs take about two weeks. You also have to make your own Google Cloud project.

Is it free? What do you get from it?

It is free and it stays free. There are no ads, no tracking and no paid version. The code is under the MIT licence. This page has no analytics.

Will it make the same playlist twice if I run it again?

Yes. Each create makes a new playlist. Delete the old one in YouTube Music if you do not need it.

It says my headers are missing a value.

Copy the headers of a request named browse that uses POST, while you are logged in. The headers must include cookie and x-goog-authuser. Then save them to headers.txt again.

Can I use it for my playlists?

Not yet. Your playlists are in Playlist1.json in the same export. Pull requests are welcome.
